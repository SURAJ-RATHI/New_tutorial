# 1. What Is a Ratio?

A ratio is used to compare two or more quantities.

In Hindi, Ratio is called **अनुपात**.

### Example

Ram has ₹100.

Shyam has ₹200.

We can say:

- Shyam has twice as much money as Ram.
- Ram has half as much money as Shyam.

Instead of writing the full values every time, we can compare them using a ratio.

Ram : Shyam = 100 : 200

Divide both numbers by 100.

= 1 : 2

Therefore, the ratio is **1 : 2**.

### Basic Definition

A ratio compares quantities by division.

If two quantities are `a` and `b`, their ratio is:

`a : b`

It can also be written as:

`a/b`

### Important Terms

For the ratio `3 : 5`:

- First term = 3
- Second term = 5
- Antecedent = 3
- Consequent = 5

**Remember:** The order of the quantities matters.

`3 : 5` is not the same as `5 : 3`.

---

# 2. Ratio and Fraction

A ratio can be written in fractional form.

For example:

`2 : 3 = 2/3`

Both can compare two quantities.

### Example 1

Ram has ₹40 and Shyam has ₹80.

Ram : Shyam = 40 : 80

= 1 : 2

As a fraction:

Ram/Shyam = 40/80 = 1/2

### Example 2

Shyam : Ram = 80 : 40

= 2 : 1

As a fraction:

Shyam/Ram = 80/40 = 2/1

### Golden Rule

The quantity being compared goes in the numerator, and the quantity used as the comparison base goes in the denominator.

Always follow the order asked in the question.

---

# 3. Simplification of Ratios

A ratio should generally be expressed in its simplest form.

### Rule

Divide both terms by their Highest Common Factor (HCF).

### Example 1

Simplify `45 : 95`.

The HCF of 45 and 95 is 5.

45 ÷ 5 = 9

95 ÷ 5 = 19

Answer = **9 : 19**

### Example 2

Simplify `125 : 135`.

Divide both terms by 5.

= 25 : 27

Answer = **25 : 27**

### Example 3

Simplify `64 : 124`.

Divide both terms by 2.

= 32 : 62

Again divide by 2.

= 16 : 31

Answer = **16 : 31**

### Example 4

Simplify `80 : 128`.

Divide both terms by 16.

80 ÷ 16 = 5

128 ÷ 16 = 8

Answer = **5 : 8**

### Shortcut

If you cannot find the HCF immediately, divide both terms by a common factor repeatedly.

For example:

`80 : 128`

= `40 : 64`

= `20 : 32`

= `10 : 16`

= `5 : 8`

### Important Rule

You must divide both terms by the same number.

Correct:

`24 : 36 = 2 : 3`

Incorrect:

Dividing 24 by 2 and 36 by 3.

# 4. Important Rules of Ratio

## Rule 1: Units Must Be the Same

You can compare quantities directly only when they are expressed in compatible units.

### Example

Compare 2 metres and 50 centimetres.

First convert both into centimetres.

2 metres = 200 centimetres

Ratio = 200 : 50

= **4 : 1**

### Example of Incompatible Units

Compare ₹100 and 50 kilometres.

These are different kinds of quantities, so a meaningful ratio cannot be formed directly.

**Trick:** Before calculating a ratio, check the units.

---

## Rule 2: Multiplying Both Terms by the Same Number

The ratio remains unchanged.

Example:

`2 : 3`

Multiply both terms by 4.

= `8 : 12`

Both simplify to `2 : 3`.

Therefore:

`2 : 3 = 8 : 12`

## Rule 3: Dividing Both Terms by the Same Common Factor

The ratio remains unchanged.

Example:

`20 : 30`

Divide both terms by 10.

= `2 : 3`

## Rule 4: Ratios Do Not Tell You the Actual Values

Suppose the ratio of two people's money is `2 : 3`.

Their actual amounts could be:

- ₹20 and ₹30
- ₹40 and ₹60
- ₹100 and ₹150
- ₹200 and ₹300

All have the same ratio.

Therefore, the actual values cannot be determined from the ratio alone.

# 5. What Is Proportion?

In Hindi, Proportion is called **समानुपात**.

When two ratios are equal, they are said to be in proportion.

### Example

`2 : 3` and `4 : 6`

Simplify the second ratio:

4 : 6 = 2 : 3

Both ratios are equal.

Therefore:

`2 : 3 = 4 : 6`

We say that 2, 3, 4 and 6 are in proportion.

### Another Example

Check whether `40 : 50` and `80 : 100` are in proportion.

First ratio:

40 : 50 = 4 : 5

Second ratio:

80 : 100 = 4 : 5

Both ratios are equal.

Therefore, they are in proportion.

### Cross-Multiplication Trick

If:

`a : b = c : d`

Then:

`a/b = c/d`

Cross-multiplying:

`a × d = b × c`

### Example

Check whether `3 : 4` and `9 : 12` are in proportion.

3 × 12 = 36

4 × 9 = 36

Both products are equal.

Therefore, the ratios are in proportion.

### Formula

`a : b = c : d`

If `a × d = b × c`, the four quantities are in proportion, provided the ratios are defined.

# 6. Equivalent Ratios

Equivalent ratios are ratios that represent the same comparison.

### Example

`2 : 3`

Multiply both terms by 2.

= `4 : 6`

Multiply both terms by 5.

= `10 : 15`

Therefore:

`2 : 3 = 4 : 6 = 10 : 15`

### Important Concept

Many different pairs of actual values can produce the same simplified ratio.

For example:

| Actual Values | Simplified Ratio |
|---|---|
| 20 : 30 | 2 : 3 |
| 40 : 60 | 2 : 3 |
| 100 : 150 | 2 : 3 |
| 200 : 300 | 2 : 3 |

### Exam Trick

If a question gives a ratio but not the actual quantities, represent the quantities using a variable.

For example:

If A : B = 4 : 5,

then:

A = 4x

B = 5x

Here, `x` represents the common multiplier.

This method is explained in the next section.

# 7. Converting a Ratio into Actual Values

Suppose:

A : B = 4 : 5

The actual values are not known.

Let the common multiplier be `x`.

Then:

A = 4x

B = 5x

### Example

The ratio of two numbers is 4 : 5, and their sum is 72. Find the numbers.

Let the numbers be:

4x and 5x

Their sum is 72.

4x + 5x = 72

9x = 72

x = 8

First number = 4 × 8 = 32

Second number = 5 × 8 = 40

**Answer: 32 and 40**

### Why Do We Use x?

Because a ratio gives only the relative sizes of the quantities, not their actual values.

The variable represents the unknown common multiplier.

### Important Formula

If A : B = a : b and A + B = S, then:

A = `a/(a+b) × S`

B = `b/(a+b) × S`

### Example

Divide 140 in the ratio 2 : 3.

Total ratio units:

2 + 3 = 5

One unit:

140 ÷ 5 = 28

First share:

2 × 28 = 56

Second share:

3 × 28 = 84

Answer = **56 and 84**

# 8. The X Method

The X method is useful when a ratio is given and you need to find the actual quantities.

### Example

A : B = 3 : 7

The sum of A and B is 100.

Let:

A = 3x

B = 7x

Then:

3x + 7x = 100

10x = 100

x = 10

Therefore:

A = 3 × 10 = 30

B = 7 × 10 = 70

Answer = **30 and 70**

### When to Use This Method

Use the X method when:

- The ratio is given.
- The sum or difference of the quantities is given.
- The actual quantities are unknown.
- You need to form equations.

# 9. Subtraction of Ratios — Internal Gap Trick

This is a special method demonstrated in the transcript for certain competitive-exam questions.

**Important:** Do not subtract ratios blindly. First understand what the question represents and check whether the internal differences are equal.

## What Is the Internal Gap?

For a ratio `a : b`, the internal gap is the absolute difference between its terms.

Gap = `|a - b|`

Examples:

- Gap of 2 : 3 = 1
- Gap of 4 : 5 = 1
- Gap of 4 : 9 = 5
- Gap of 9 : 14 = 5

## When the Gaps Are Equal

Suppose the two ratios are:

`2 : 3`

`4 : 5`

Their internal gaps are both 1.

In a question where the ratios represent corresponding quantities at two different times or stages, their differences may be compared using this method.

For example, if the difference between the corresponding quantities is known to be 10:

- First ratio difference = 3 - 2 = 1 unit
- Second ratio difference = 5 - 4 = 1 unit

The same one-unit difference represents the same actual difference, provided the problem's conditions justify the comparison.

## When the Gaps Are Not Equal

Suppose the ratios are:

`3 : 5`

`7 : 11`

First gap:

5 - 3 = 2

Second gap:

11 - 7 = 4

The gaps are different.

Before using a subtraction-based comparison, the ratios must be converted to an appropriate equivalent form so the internal gaps match, if the problem's conditions allow this.

For example, multiply `3 : 5` by 2:

`6 : 10`

Now the gap is:

10 - 6 = 4

The second ratio is:

`7 : 11`

Its gap is also:

11 - 7 = 4

The internal gaps now match.

### Important Warning

Scaling a ratio changes the size of its ratio units. Matching internal gaps is a technique for particular ratio-comparison problems, not a universal rule that makes arbitrary ratios subtractable.

Always check what the ratios represent.

# 10. Dividing an Amount in a Given Ratio

This is one of the most important question patterns.

### Formula

If an amount `S` is divided in the ratio `a : b`:

First share = `a/(a+b) × S`

Second share = `b/(a+b) × S`

### Example 1

Divide ₹140 in the ratio 2 : 3.

Total units:

2 + 3 = 5

Value of one unit:

140 ÷ 5 = 28

First share:

2 × 28 = ₹56

Second share:

3 × 28 = ₹84

Answer = **₹56 and ₹84**

### Shortcut

First share:

`140 × 2/5 = 56`

Second share:

`140 × 3/5 = 84`

### Example 2

Divide ₹720 in the ratio 5 : 7.

Total units:

5 + 7 = 12

First share:

720 × 5/12 = ₹300

Second share:

720 × 7/12 = ₹420

Answer = **₹300 and ₹420**

### Three Shares

Divide ₹600 in the ratio 2 : 3 : 5.

Total units:

2 + 3 + 5 = 10

One unit:

600 ÷ 10 = 60

First share = 2 × 60 = ₹120

Second share = 3 × 60 = ₹180

Third share = 5 × 60 = ₹300

Answer = **₹120, ₹180 and ₹300**

# 11. Ratio of Three Quantities

Suppose:

A : B = 2 : 3

B : C = 6 : 7

Find A : B : C.

Notice that B appears in both ratios.

In the first ratio, B = 3.

In the second ratio, B = 6.

These values must be made equal.

Multiply the first ratio by 2:

A : B = 4 : 6

The second ratio remains:

B : C = 6 : 7

Now combine them.

A : B : C = **4 : 6 : 7**

## The Impostor Idea

The common quantity appears in two different ratios.

It is like an "impostor" appearing in two places with different values.

Make that common quantity equal in both ratios before combining them.

### Example 2

A : B = 5 : 14

B : C = 7 : 9

The common quantity is B.

In the first ratio, B = 14.

In the second ratio, B = 7.

Multiply the second ratio by 2:

B : C = 14 : 18

Now combine:

A : B : C = **5 : 14 : 18**

### Rule

For:

A : B = a : b

B : C = c : d

Make the two values of B equal, then combine the ratios.

---

# 12. Ratio of Four Quantities

The same concept can be extended to four quantities.

Suppose:

A : B = 2 : 3

B : C = 6 : 7

C : D = 14 : 5

Find A : B : C : D.

### Step 1: Combine A, B and C

A : B = 2 : 3

B : C = 6 : 7

Make B equal:

A : B = 4 : 6

B : C = 6 : 7

Therefore:

A : B : C = 4 : 6 : 7

### Step 2: Combine C and D

C : D = 14 : 5

But C is 7 in the combined ratio.

Multiply `4 : 6 : 7` by 2:

A : B : C = 8 : 12 : 14

Now combine with:

C : D = 14 : 5

Final ratio:

**A : B : C : D = 8 : 12 : 14 : 5**

### Trick

Always make the common quantity equal before joining two ratios.

# 13. The Impostor (बहुरूपिया) Approach

This approach is useful for combining ratios involving three or more quantities.

### Example

A : B = 2 : 3

B : C = 6 : 7

Find A : B : C.

The common quantity B appears as:

- 3 in the first ratio
- 6 in the second ratio

Make B equal by multiplying the first ratio by 2.

A : B = 4 : 6

B : C = 6 : 7

Answer:

**A : B : C = 4 : 6 : 7**

### Another Example

A : B = 5 : 14

B : C = 7 : 9

Make B equal to 14.

Multiply the second ratio by 2.

B : C = 14 : 18

Combine:

A : B : C = **5 : 14 : 18**

### How to Recognize the Pattern

Use this approach when:

- Two ratios share a common variable.
- The common variable has different values in the two ratios.
- You need a combined ratio.

**Remember:** When you multiply one term of a ratio, multiply every term of that ratio by the same number.

# 14. The Inverted N Approach

This is a shortcut for certain connected ratios.

Suppose:

A : B = 2 : 3

B : C = 6 : 7

The ratios form a connected chain:

A → B → C

A shortcut is to multiply the outer terms and the shared middle terms.

A is proportional to:

2 × 6 = 12

B is proportional to:

3 × 6 = 18

C is proportional to:

3 × 7 = 21

So the combined ratio is:

12 : 18 : 21

Divide by 3:

**4 : 6 : 7**

### Another Example

A : B = 5 : 14

B : C = 7 : 9

Using the connected-ratio shortcut:

A = 5 × 7 = 35

B = 14 × 7 = 98

C = 14 × 9 = 126

Ratio:

35 : 98 : 126

Divide by 7:

**5 : 14 : 18**

### Important Condition

Use this shortcut when the ratios form a connected chain through their shared variable.

If the ratios are disconnected, such as:

A : B = 10 : 3

A : C = 5 : 6

the chain is not A → B → C through B. Use the impostor approach instead.

# 15. The Hanging Number (लटकन) Approach

This method is useful for equations such as:

`2A = 3B = 4C`

We need to find:

A : B : C

### Method

Take the LCM of the coefficients.

LCM of 2, 3 and 4 = 12

Since:

2A = 12

A = 12/2 = 6

Similarly:

3B = 12

B = 12/3 = 4

And:

4C = 12

C = 12/4 = 3

Therefore:

**A : B : C = 6 : 4 : 3**

### Shortcut

For:

`aA = bB = cC`

The ratio is:

`1/a : 1/b : 1/c`

Convert to whole numbers using the LCM of the denominators.

For `2A = 3B = 4C`:

A : B : C = 1/2 : 1/3 : 1/4

Multiply every term by 12:

= 6 : 4 : 3

### Important

Do not write `2 : 3 : 4` directly.

The coefficients are multiplied by the variables, so the variables are inversely proportional to those coefficients.

---

# 16. The Hide-and-Seek (लुकाछुपी) Approach

This is another shortcut for equations such as:

`2A = 3B = 4C`

To find the ratio of one variable, hide that variable and multiply the other coefficients.

### Find A

Hide A.

Multiply the coefficients of B and C:

3 × 4 = 12

### Find B

Hide B.

Multiply the coefficients of A and C:

2 × 4 = 8

### Find C

Hide C.

Multiply the coefficients of A and B:

2 × 3 = 6

The ratio is:

12 : 8 : 6

Simplify by dividing by 2.

**A : B : C = 6 : 4 : 3**

### Example 2

`A/3 = B/4 = C/5`

The variables are proportional to 3, 4 and 5.

Therefore:

**A : B : C = 3 : 4 : 5**

Be careful: this is different from `3A = 4B = 5C`, where the coefficients are multiplied by the variables.

### Best Practice

First identify the exact equation. Do not apply the shortcut without checking whether the variables are multiplied or divided by the coefficients.

# 17. Ratio Equations

These questions provide equations such as:

`2A = 3B`

Find A : B.

Divide both sides by 2 and 3 appropriately:

A/B = 3/2

Therefore:

**A : B = 3 : 2**

### Example 1

`3A = 5B`

A/B = 5/3

Answer:

**A : B = 5 : 3**

### Example 2

`2A = 3B = 4C`

From the hanging number or hide-and-seek method:

**A : B : C = 6 : 4 : 3**

### Golden Rule

If:

`aA = bB`

then:

`A : B = b : a`

The coefficients reverse when you solve for the ratio of the variables.

# 18. Ratios Containing Fractions

Sometimes the given ratio contains fractions.

Example:

`1/2 : 50/3 : 1/4`

We need to convert the ratio into whole numbers.

### Step 1: Identify the Denominators

The denominators are:

2, 3 and 4

LCM = 12

### Step 2: Multiply Every Term by 12

First term:

12 × 1/2 = 6

Second term:

12 × 50/3 = 200

Third term:

12 × 1/4 = 3

Therefore:

**6 : 200 : 3**

### Important Rule

To remove fractions from a ratio:

1. Find the LCM of all denominators.
2. Multiply every term by that LCM.
3. Simplify the resulting whole-number ratio if possible.

### Example 2

Simplify:

`1/3 : 1/4`

LCM of 3 and 4 = 12

Multiply both terms by 12.

= 4 : 3

Answer = **4 : 3**

# 19. Coin-Based Questions

Coin questions often ask how many coins of each type are present when the total monetary value is given.

### Important Rule

Convert every coin into the same unit, usually rupees or paise, before forming the ratio.

| Coin | Value in Rupees |
|---|---:|
| 50 paise | ₹0.50 |
| 25 paise | ₹0.25 |
| ₹1 | ₹1 |
| ₹2 | ₹2 |
| ₹5 | ₹5 |

### Example 1: Coin Count Ratio

The number of 50-paise coins and ₹1 coins is in the ratio 2 : 3.

Find the ratio of their monetary values.

Value of 50-paise coins:

2 × ₹0.50 = ₹1

Value of ₹1 coins:

3 × ₹1 = ₹3

Monetary-value ratio:

1 : 3

Answer = **1 : 3**

### Example 2: Find the Number of Coins

The numbers of 50-paise, 25-paise and ₹1 coins are in the ratio 2 : 4 : 1.

Their total value is ₹55.

Find the number of 25-paise coins.

Let the number of coins be:

- 50-paise coins = 2x
- 25-paise coins = 4x
- ₹1 coins = x

Convert the coin values to rupees.

Total value:

`2x × 0.50 + 4x × 0.25 + x × 1 = 55`

Simplify:

`x + x + x = 55`

`3x = 55`

`x = 55/3`

This does not give a whole number of coins, so these particular values do not produce a valid whole-number coin count.

**Lesson:** In coin questions, always check whether your final number of coins is a whole number. If it is not, recheck the given data or calculation.

### General Method

1. Write the ratio of the number of coins.
2. Assign variables such as `2x`, `4x`, `x`.
3. Multiply each count by the value of its coin.
4. Add the monetary values.
5. Equate the total to the amount given.
6. Solve for `x`.
7. Calculate the required number of coins.

### Important Difference

The ratio of the number of coins is not always the same as the ratio of their monetary values.

# 20. Number-Based Questions

These questions involve two or more numbers whose ratio and sum or difference are given.

### Example 1: Sum Given

Two numbers are in the ratio 3 : 5. Their sum is 64. Find the numbers.

Let the numbers be:

3x and 5x

3x + 5x = 64

8x = 64

x = 8

Numbers:

3 × 8 = 24

5 × 8 = 40

Answer = **24 and 40**

### Example 2: Difference Given

Two numbers are in the ratio 4 : 7. Their difference is 21. Find the numbers.

Let the numbers be:

4x and 7x

Difference:

7x - 4x = 21

3x = 21

x = 7

Numbers:

4 × 7 = 28

7 × 7 = 49

Answer = **28 and 49**

### Formula

If the ratio is `a : b` and the sum is `S`:

First number = `aS/(a+b)`

Second number = `bS/(a+b)`

If the difference is `D`:

Smaller number = `aD/(b-a)`

Larger number = `bD/(b-a)`

Here, assume `b > a`.

# 21. Income and Expenditure Questions

These questions use ratios to compare income, expenditure and savings.

### Main Relationship

Income = Expenditure + Savings

Savings = Income - Expenditure

Expenditure = Income - Savings

### Example 1

A person's income and expenditure are in the ratio 5 : 3.

If the income is ₹40,000, find the expenditure and savings.

Income ratio units = 5

Expenditure ratio units = 3

One ratio unit:

40,000 ÷ 5 = 8,000

Expenditure:

3 × 8,000 = ₹24,000

Savings:

40,000 - 24,000 = ₹16,000

Answer:

- Income = ₹40,000
- Expenditure = ₹24,000
- Savings = ₹16,000

### Example 2

Expenditure is 40% more than savings.

Assume savings = ₹100.

Expenditure = ₹140.

Income = Savings + Expenditure

= 100 + 140

= ₹240

Savings percentage of income:

100/240 × 100

= 41.66...%

### Trick

When a question gives a comparison between expenditure and savings, assume a convenient value for one of them.

Then calculate the other quantity and add them to get income.

# 22. Age-Based Questions

Age questions often give:
- The present age ratio.
- A future or past age ratio.
- The number of years between the two situations.
- A question asking for present ages or their difference.

### Important Rule

If a person is currently `x` years old, after `n` years their age will be:

`x + n`

Age always increases by the same number of years for each person.

### Example 1: Present and Future Ratio

The present ages of a mother and daughter are in the ratio 7 : 1.

After 5 years, their ages will be in the ratio 4 : 1.

Find the difference between their present ages.

Let the present ages be:

Mother = 7x

Daughter = x

After 5 years:

Mother = 7x + 5

Daughter = x + 5

The future ratio is 4 : 1.

Therefore:

`(7x + 5)/(x + 5) = 4/1`

Cross-multiply:

7x + 5 = 4x + 20

3x = 15

x = 5

Present ages:

Mother = 7 × 5 = 35 years

Daughter = 5 years

Difference:

35 - 5 = 30 years

**Answer: 30 years**

### Example 2: Present Ratio and Age Difference

The present ages of two people are in the ratio 3 : 2.

Their age difference is 10 years.

Find their present ages.

Let the ages be:

3x and 2x

Difference:

3x - 2x = 10

x = 10

Ages:

30 years and 20 years

Answer = **30 years and 20 years**

### Age Question Checklist

1. Identify whether the ratio is present, past or future.
2. Represent present ages using variables.
3. Add years for future ages.
4. Subtract years for past ages.
5. Form the ratio equation.
6. Solve for the variable.
7. Answer the exact question asked.

# 23. Common Mistakes

1. Comparing quantities with incompatible units.
2. Reversing the order of a ratio.
3. Simplifying only one term instead of both.
4. Assuming that a ratio tells you the actual values.
5. Forgetting to make common quantities equal before combining ratios.
6. Adding ratios without checking whether the shared term matches.
7. Using the inverted N shortcut when the ratios are not connected.
8. Confusing `2A = 3B` with `A/2 = B/3`.
9. Forgetting that the variables reverse in equations such as `2A = 3B`.
10. Subtracting ratios without checking the internal gaps and the meaning of the quantities.
11. Confusing the ratio of coin counts with the ratio of their total monetary values.
12. Forgetting to convert coin values into the same monetary unit.
13. Forgetting that age increases by the same number of years for each person.
14. Using the wrong base when calculating income, expenditure or savings.
15. Forgetting to simplify the final ratio.

# 🎯 Final Exam Strategy

1. Learn ratio simplification until you can do it quickly.
2. Always check the units before comparing quantities.
3. Remember that ratios show relative values, not actual values.
4. Use `x` to represent the common multiplier when actual quantities are unknown.
5. For three or more quantities, make shared terms equal before combining ratios.
6. Use shortcuts such as inverted N, hanging number and hide-and-seek only when their conditions are satisfied.
7. For fraction ratios, clear the denominators using the LCM.
8. For coin problems, distinguish the number of coins from their monetary values.
9. For age problems, represent present ages first and then add or subtract years.
10. For every question, check whether it asks for a ratio, an actual value, a sum, a difference or a share.

**Golden Rule:** A ratio becomes easy when you identify the common quantity, make the units compatible, and use the correct multiplier.

## 1. Ratio kya hota hai?

- Ratio ka matlab = **Comparison** (tulna).
- Jab bhi hum 2 cheezon ko compare karte hain, hum ratio use karte hain.
- Hindi mein: **Anupaat**.

**Example (kyun invent hua):**
Ram ke paas ₹100 hai, Shyam ke paas ₹200. Dono apni exact income batana nahi chahte, lekin compare karna chahte hain.

- "Shyam ke paas Ram se **double** hai" → Shyam : Ram = **2 : 1**
- "Ram ke paas Shyam ka **aadha** hai" → Ram : Shyam = **1 : 2**

Exact value chhupi rahi, comparison bhi ho gaya. Yahi ratio ka kaam hai.

---

## 2. Ratio = Fraction (dono same cheez hain)

- Fraction bhi compare karne ke liye use hota hai, ratio bhi.
- **Rule:** Jis se compare kar rahe ho (jiske *saath*), wo **neeche (denominator)**. Jiski baat ho rahi hai, wo **upar (numerator)**.

| Statement | Fraction | Ratio |
|---|---|---|
| Ram ki Shyam se tulna (Ram : Shyam) | 1/2 | 1 : 2 |
| Shyam ki Ram se tulna (Shyam : Ram) | 2/1 | 2 : 1 |

**Yaad rakhne ka tareeka:** "Kiski baat? → upar. Kisse compare? → neeche."

## 3. Ratio Simplify karna

**Trick:** Dono numbers ko ek **common number** se divide karo jab tak aur divide na ho sake (HCF se ek baar mein bhi ho jaata hai).

| Given | Common divisor | Simplified |
|---|---|---|
| 45 : 95 | 5 | **9 : 19** |
| 125 : 135 | 5 | **25 : 27** |
| 64 : 124 | 2, phir 2 | 32:62 → **16 : 31** |
| 80 : 128 | 4, 2, 2 (ya seedha 16) | **5 : 8** |

**Tip:** Agar bada number ek baar mein samajh na aaye, to chhote-chhote tukdon mein (2, 4 se) divide karo. Kuch galat nahi hai.

**Likhne/bolne ka tareeka:** 16 : 31 ko bolte hain "16 is to 31" ya Hindi mein "16 anupaat 31".

---

## 4. Golden Rule: UNITS SAME honi chahiye

- Ratio hamesha **same units** ke beech hota hai.
- Length ki length se, area ki area se, colour ki colour se, rupaye ki rupaye se compare hoti hai.

**Example:** ₹ aur km ka ratio **possible hi nahi** hai. Aisa question aaye to answer: **"Cannot be determined / not possible"** (video mein ise option C & D / "CND" bola gaya tha).

Trap: Kuch students ₹100 : 600 km ka ratio 1:6 bana dete hain. **Galat!**

## 5. Proportion kya hota hai?

- Hindi: **Samaan anupaat**.
- Jab **do ratios aapas mein equal** ho, to unhe **proportion** kehte hain.

**Kaise check karein:** Dono ratios ko simplify karo. Agar simplified value same aaye → **proportion me hain**. Warna → **not in proportion**.

**Examples:**

- 2 : 3 aur 4 : 6 → 4:6 ko 2 se divide = 2:3 → **Proportion ✔**
- 40 : 50 aur 80 : 100 → pehla = 4:5, doosra = 4:5 → **Proportion ✔**
  (Likhte hain: "40, 50, 80 and 100 are in proportion")

**Note:** Ye basic lagta hai, lekin Mains mein "values proportional hain" jaise words aate hain. Isliye term clear honi chahiye.

## 6. Ratio se Real Value – "x" kyun lagate hain?

**Observation:** Alag-alag real values ka ratio same ho sakta hai.

| Real values | Simplified ratio | Multiplier (2:3 se real tak) |
|---|---|---|
| 20 : 30 | 2 : 3 | × 10 |
| 40 : 60 | 2 : 3 | × 20 |
| 100 : 150 | 2 : 3 | × 50 |
| 30 : 45 | 2 : 3 | × 15 |

**Key lessons:**

1. Ek hi ratio ke peeche **anginat (infinite)** real values ho sakti hain.
2. Ratio se real value tak jaane ke liye **ek unique number** se **dono ko multiply** karna padta hai (wahi same number dono par).
3. Agar real value pata nahi hai, to us unique number ko **x** maan lo.

**Isiliye:** Ratio 4 : 5 ho to hum likhte hain **4x aur 5x**. Ratio par directly calculation nahi ho sakti, pehle usse real value (x ke through) me convert karna padta hai.

**Imp:** Ek ratio ka "1 unit" sirf usi ratio set ke liye valid hai. Alag ratio set ke liye alag unit hoga (aage question me dikhega).

## 7. Subtraction of Ratios (Internal Gap Concept)

Do ratios ko aapas me **subtract** kar sakte hain, **sirf tab jab dono ka internal gap SAME ho**.

**Internal gap = ratio ke dono parts ka difference.**

### Examples (gap already same)

- 4 : 9 aur 9 : 14 → gap 5 aur 5 → subtract: **5 : 5** ✔
- 2 : 3 aur 4 : 5 → gap 1 aur 1 → subtract karke (4−2) : (5−3) = **2 : 2** ✔

### Wrong example (jo galat hai, note karo)

- 3 : 4 aur 7 : 9 → gap 1 aur 2 (**same nahi**) → seedha subtract karna **GALAT** hai. Pehle gap same karna padega.

### Gap same kaise karein (Trick)

**Step 1:** Dono ratios ka gap nikalo.
**Step 2:** Kisi ratio ko ek number se multiply karke gap barabar karo.
**Step 3:** Ab subtract karo.

**Example A:** 3 : 5 aur 7 : 11
- Gap: 2 aur 4
- Pehle ratio ko 2 se multiply: 6 : 10 (gap 4)
- Ab subtract: (7−6) : (11−10) = **1 : 1**

**Example B:** 5 : 11 aur 4 : 7
- Gap: 6 aur 3
- Doosre ko 2 se multiply: 8 : 14 (gap 6)
- Subtract: (8−5) : (14−11) = **3 : 3**

**Example C (cross-multiply trick):** 7 : 9 aur 11 : 14
- Gap: 2 aur 3
- Pehle ko **3** se (gap 6), doosre ko **2** se (gap 6) multiply karo → 21 : 27 aur 22 : 28
- Subtract: **1 : 1**

**Rule of thumb:** Gap alag-alag ho to **cross multiply** karke gap same banao.

## 8. Distribution of Money in a Ratio

**Question:** ₹140 ko Rahul aur Aul me 2 : 3 ke ratio me baantna hai.

### Method 1 (Unit method – sabse safe)

1. Total ratio units = 2 + 3 = **5**
2. 5 units = ₹140 → **1 unit = 140 ÷ 5 = ₹28**
3. Rahul = 2 × 28 = **₹56**
4. Aul = 3 × 28 = **₹84**

### Method 2 (Shortcut)

**Share = Total amount × (person ka ratio part) ÷ (total ratio)**

- Rahul = 140 × 2 / 5 = **56**
- Aul = 140 × 3 / 5 = **84**

**Yaad rakho:** "Jiska hissa chahiye, uska ratio multiply, total se divide."

**Golden line:** Agar **1 unit** ki value mil gayi, to poora brahmaand tumhare haath me hai.

## 9. Combining Ratios: A:B aur B:C se A:B:C

### 9.1 Bahurupiya Approach (Universal – kabhi fail nahi hota)

**Idea:** Jo letter **do jagah** hai lekin **alag numbers** ke saath (bahurupiya = disguise me), use pakdo aur uske numbers **same** karo (dono ratios ko multiply karke).

**Example 1:** A : B = 2 : 3 aur B : C = 6 : 7
- B bahurupiya hai (3 aur 6).
- Pehle ratio ko 2 se multiply: A : B = 4 : 6
- Ab B same hai (6) → **A : B : C = 4 : 6 : 7**

**Example 2:** A : B = 5 : 14 aur B : C = 7 : 9
- B: 14 aur 7. Doosre ratio ko 2 se multiply: B : C = 14 : 18
- **A : B : C = 5 : 14 : 18**

**Example 3 (bahurupiya A ho sakta hai):** A : B = 2 : 3 aur A : C = 5 : 6
- A: 2 aur 5 → LCM 10
- Pehle ko 5 se multiply: A : B = 10 : 15
- Doosre ko 2 se multiply: A : C = 10 : 12
- **A : B : C = 10 : 15 : 12**

> Bahurupiya sirf B hi nahi, kabhi bhi A ya C ho sakta hai.

### 9.2 "Ulta-N" Approach (Cross multiplication – sirf shortcut)

**Kab lagta hai:** Jab ek ratio ka **end** doosre ratio ka **start** ho (A:B, **B**:C). Yani chain continuous ho.

**Example:** A : B = 5 : 14 aur B : C = 7 : 9
- A = 5 × 7 = 35
- B = 14 × 7 = 98
- C = 14 × 9 = 126
- Ab 7 se divide: **5 : 14 : 18** ✔

**Kab FAIL hota hai:** Jab chain continuous nahi hai, jaise A:B aur **A**:C (A dono me repeat). Example 3 me Ulta-N lagane se galat answer aata hai.

**Lesson:** Pata hona chahiye kaun si approach kahan lagti hai. Agar confusion ho to **Bahurupiya** use karo (ye hamesha kaam karta hai).

## 10. Trick: 2A = 3B (aur 2A = 3B = 4C)

### 10.1 Do variables: 2A = 3B

**Shortcut ("padosan"/side-by-side approach):**
- A ke saamne **B ka number**, B ke saamne **A ka number**.
- 2A = 3B → **A : B = 3 : 2**

### 10.2 Teen variables: 2A = 3B = 4C

**Method 1 – Latkan (Hanging) Approach:**
1. Letters ke saamne wale numbers (2, 3, 4) ka **LCM** lo = 12.
2. 12 ko har number se divide karo:
   - A = 12 ÷ 2 = **6**
   - B = 12 ÷ 3 = **4**
   - C = 12 ÷ 4 = **3**
3. **A : B : C = 6 : 4 : 3**

**Method 2 – Hide and Seek (Lukachuppi) Approach:**
- Jis letter ki value chahiye use **chhupa do**, baaki bache numbers ko **multiply** karo.
- A chahiye → B aur C ke numbers multiply: 3 × 4 = **12**
- B chahiye → A aur C: 2 × 4 = **8**
- C chahiye → A aur B: 2 × 3 = **6**
- **12 : 8 : 6** → simplify (÷2) → **6 : 4 : 3** ✔

**Another example (practice):** 3A = 4B = 6C
- Hide & Seek: A = 4×6 = 24, B = 3×6 = 18, C = 3×4 = 12 → 24:18:12 → **4 : 3 : 2**

**Example (video):** 5A = 3B = 4C (type ka question) bhi isi tarah hoga: A = 3×4 = 12, B = 5×4 = 20, C = 5×3 = 15 → **12 : 20 : 15**.

## 11. Fractions wale ratio ko Whole Numbers me convert karna

**Rule:** Ratios hamesha **whole numbers** me hote hain, fractions me nahi.

**Steps:**
1. Mixed fraction ko improper banao.
2. Sab **denominators ka LCM** lo.
3. Us LCM se **sabko multiply** karo.

**Example:** 1/2 : 16 2/3 : 1/4
- 16 2/3 = (16×3 + 2)/3 = **50/3**
- Denominators: 2, 3, 4 → LCM = **12**
- Multiply: (1/2)×12 = **6**, (50/3)×12 = **200**, (1/4)×12 = **3**
- **Ratio = 6 : 200 : 3**

## 12. Chaar (4) Quantities: A : B : C : D

Given: A : B, B : C, C : D → A : B : C : D nikalna hai.

### 12.1 Zameen Kabza Approach (Land-grabbing)

**Idea:** Khaali jagah ko **padosi number** bhar deta hai. Phir **vertical multiply** karo.

**Example:** A : B = 2 : 3, B : C = 4 : 5, C : D = 1 : 2

Table:

| | A | B | C | D |
|---|---|---|---|---|
| A:B | 2 | 3 | – | – |
| B:C | – | 4 | 5 | – |
| C:D | – | – | 1 | 2 |

Khaali jagah padosi se bharo (left se padosi ka number, right se padosi ka):

- A column: 2, 4, 1 ... video me method: har column ke number multiply karne se:
  - A = 2 × 4 × 1 = **8**
  - B = 3 × 4 × 1 = **12**
  - C = 3 × 5 × 1 = **15**
  - D = 3 × 5 × 2 = **30**
- **A : B : C : D = 8 : 12 : 15 : 30**

### 12.2 Sandwich Approach (same question, naya tareeka)

**Example:** A : B = 1 : 5, B : C = 2 : 3, C : D = 4 : 7

**Bread (pehle vertical multiply, A–B–C ke "start" wale numbers):**
- A = 1 × 2 × 4 = **8**
- D = 5 × 3 × 7 = **105**

**Aloo (filling – beech wale numbers):**
- B = 5 × 2 × 4 = **40**
- C = 5 × 3 × 4 = **60**

**Final: A : B : C : D = 8 : 40 : 60 : 105** (Zameen Kabza se bhi yahi aata hai.)

Shortcut sochne ka tareeka: **Aage wale numbers ka multiplication aur peeche wale numbers ka multiplication** milakar dono ko beech ke numbers se adjust karte jao.

### 12.3 Mahabharat Approach (sirf A : D chahiye ho)

**Idea:** Kaurav (denominator wale numbers) aur Pandav (numerator wale numbers) ki do team. Aamne-saamne wale **same players ko kaat do**.

**Formula:**

**A : D = (A-parts ka product) : (B-parts ka product)**

Jaise A:B = a1:b1, B:C = a2:b2, C:D = a3:b3 to

**A : D = (a1 × a2 × a3) : (b1 × b2 × b3)**

**Example:** A : B = 2 : 3, B : C = 7 : 2, C : D = 6 : 1
- A : D = (2 × 7 × 6) : (3 × 2 × 1) = 84 : 6 = **14 : 1**
- Pehle hi cancel kar do: 2 aur 2 cancel, 6 aur 3 cancel → quick answer.

> Jab sirf pehla aur aakhri part poochha ho (A : D), tab Mahabharat approach time bachati hai.

## 13. Coins Wale Questions

### 13.1 Basic concepts (bahut zaroori)

**Concept 1: Chhote se bade me jaana = DIVIDE, bade se chhote me aana = MULTIPLY.**
(Yaad rakhne ke liye: Ground floor se upar jaane ke liye **lift** use karte ho → lift ka sign ÷ jaisa dikhta hai.)

**Concept 2: Fraction value of paise (₹1 se kam ke coins):**

Fraction value = **paise / 100**

| Paise | Fraction value of ₹1 |
|---|---|
| 25 p | 1/4 |
| 20 p | 1/5 |
| 10 p | 1/10 |
| 5 p | 1/20 |
| 50 p | 1/2 |
| 75 p | 3/4 |

(Fraction value tabhi chahiye jab coin ₹1 se chhota ho. ₹1, ₹2, ₹5 jaise coins ki value waise hi lete hain.)

**Concept 3: "Jiski lathi, uski bhains" Approach**

- Agar **total Rupees (amount)** diya hai → ratio bhi **Rupees ka** chahiye.
- Agar **total coins ki sankhya** di hai → ratio bhi **coins ka** chahiye.
- Dono mismatch ho to pehle convert karo (coins ke ratio ko rupees ke ratio me, ya ulta).

### 13.2 Solved Example 1

**Q:** Ek bag me 50 paise, 25 paise aur ₹1 ke coins 5 : 8 : 1 ke ratio me hain. Total value ₹55 hai. 25 paise ke kitne coins hain?

- Total **rupees** diya hai (₹55), ratio **coins** ka hai → mismatch. Coins ratio ko rupees ratio me badlo.
- Rupees ratio:
  - 50p: 5 × (1/2) = **2.5**
  - 25p: 8 × (1/4) = **2**
  - ₹1: 1 × 1 = **1**
- Total = 2.5 + 2 + 1 = **5.5 units** = ₹55
- 1 unit = 55 ÷ 5.5 = **10**
- 25p ke coins = **8 coins-ratio** × 10 = **80 coins** ✔

### 13.3 Solved Example 2

**Q:** Ek bag me ₹5, ₹10 aur ₹20 ke coins 2 : 3 : 5 (coins ke ratio) me hain. Total coins = 240. Total amount kitna hai?

- Total **coins** diya (240), ratio bhi **coins** ka → koi convert nahi.
- Total ratio = 2 + 3 + 5 = 10 → 1 unit = 240 ÷ 10 = **24 coins**
- ₹5 ke coins = 2 × 24 = **48** → 48 × 5 = **₹240**
- ₹10 ke coins = 3 × 24 = **72** → 72 × 10 = **₹720**
- ₹20 ke coins = 5 × 24 = **120** → 120 × 20 = **₹2400**
- **Total amount = 240 + 720 + 2400 = ₹3360** ✔

**Lesson:** Teen steps hamesha yaad rakho: (1) kya total diya hai, (2) ratio kis cheez ka hai, (3) mismatch ho to convert karo.

## 14. Same Number Add / Subtract (Increase-Decrease Questions)

**Core concept:** Agar dono quantities me **same number add** karne se ratio ban raha hai, to **Old ratio aur New ratio ko subtract** karne par jo gap aata hai wo added number ke barabar hota hai.

### Q1: Do numbers 3 : 4 me hain. Dono me 30 add karne par ratio 9 : 10 ho jaata hai. Original numbers?

- Internal gap: 3:4 ka gap 1, 9:10 ka gap 1 (same ✔)
- Subtract: (9−3) : (10−4) = **6 : 6**
- 6 units = 30 → **1 unit = 5**
- Original numbers = 3×5 = **15** aur 4×5 = **20**

### Q2: Teen classes ka ratio 3 : 4 : 5. Har class me 20 students badhne par ratio 4 : 5 : 6 ho jaata hai. Original total students?

- Gap (new − old) = 1 unit har class me → 1 unit = 20
- Original total = (3+4+5) = 12 units = 12 × 20 = **240**

### Q3 (important – alag-alag number add ho rahe hain): 3 : 5 : 8 ratio me students. Teen sections me 15, 30, 15 aur students aaye, naya ratio 4 : 7 : 9. Original total?

- Increase ratio units: 4−3 = **1** unit = 15, 7−5 = **2** units = 30, 9−8 = **1** unit = 15
- Har jagah **1 unit = 15** (consistent ✔)
- Original total = (3+5+8) = 16 units = 16 × 15 = **240**

**Note:** Yahan gap same nahi tha (2, 3), lekin humne gap ki jagah **increase ko ratio units me dekha** aur check kiya ki "1 unit" teeno me same hai. Ye isliye kaam kiya kyunki increase same unit-rate se ho raha tha.

## 15. Income – Expenditure – Savings Questions

**Basic formulas (yaad rakho):**

- **Savings = Income − Expenditure**
- **Income = Expenditure + Savings**
- **Expenditure = Income − Savings**

### Q1 (Same savings): A aur B ki income ka ratio 11 : 13, expenditure ka ratio 9 : 11. Dono ki savings ₹4000 hain. Dono ki income me difference?

**Method 1 – Subtract approach (sirf jab savings SAME ho):**
- Income ratio − Expenditure ratio:
  - A: 11 − 9 = **2 units**
  - B: 13 − 11 = **2 units** (savings same ✔)
- Ye 2 units = ₹4000 → **1 unit = ₹2000**
- Income difference = 13 − 11 = **2 units = ₹4000**

**Method 2 – "Panda Approach" (Universal – savings same ho ya na ho):**

Idea: Ek variable (expenditure) ko **eliminate** karne ke liye cross multiply karo.

- Income: A = 11x, B = 13x; Expenditure: A = 9y, B = 11y
- Equation 1: 11x − 9y = 4000; Equation 2: 13x − 11y = 4000
- Trick: **Income ratio × other's expenditure ratio** (cross):
  - 11 × 11 = 121 aur 9 × 13 = 117
  - 11 × 4000 = 44000 aur 9 × 4000 = 36000
- Subtract: 121 − 117 = **4 units**; 44000 − 36000 = **8000**
- 4 units = 8000 → **1 unit = 2000**
- Income difference = 2 units = **₹4000** ✔ (dono methods ka same answer)
- Agar individual income chahiye: A = 11 × 2000 = **₹22,000**, B = 13 × 2000 = **₹26,000**

> **Panda Approach universal hai**: savings alag ho to bhi chalegi.

### Q2 (Mains level): A aur B ki income ka ratio 5 : 3. A, B aur C ke expenditure ka ratio 8 : 5 : 2. C ₹2000 kharch karta hai aur B ₹700 bachata hai. A kitna bachata hai?

- C ka expenditure: 2 units = ₹2000 → **1 unit (expenditure) = ₹1000**
- B ka expenditure = 5 × 1000 = **₹5000**
- B ki income = 5000 + 700 = **₹5700**
- B ka income ratio = 3 units = 5700 → **1 unit (income) = ₹1900**
- A ki income = 5 × 1900 = **₹9500**
- A ka expenditure = 8 × 1000 = **₹8000**
- **A ki savings = 9500 − 8000 = ₹1500** ✔

**Warning:** Expenditure ka 1 unit (₹1000) aur income ka 1 unit (₹1900) **alag-alag** hain. Dono ko mix mat karo. Har ratio ka apna unit hota hai.

## 16. "Increase in a Ratio" – Sahara (Support) Concept

**Problem type:** Ek value ko ek ratio ke through doosre ratio me pahunchana.

**Concept:** 40 ko 2 : 3 ke ratio me increase karo.

- Old value ko **2** ka sahara milta hai, destination **3** hai.
- 2 units = 40 → 1 unit = 20
- 3 units = 3 × 20 = **60**

**Formula/Trick:** **(Value ÷ old ratio part) × new ratio part.**

(Jaise teacher "sahara" dekar student ko manzil tak pahunchata hai.)

### Solved Example (Premium question)

**Q:** A, B, C ki last year ki income 3 : 4 : 5 ke ratio me thi. Last year se current year income ke ratio A: 4 : 5, B: 2 : 3, C: 3 : 4. Agar total current year income ₹98,500 hai, to B aur C ki combined current income?

**Step 1 – Current year me convert karo (sahara):**
- A: 3 × (5/4) = **15/4**
- B: 4 × (3/2) = **6**
- C: 5 × (4/3) = **20/3**

**Step 2 – Whole numbers me lao (LCM 12):**
- A = 15/4 × 12 = **45**, B = 6 × 12 = **72**, C = 20/3 × 12 = **80**
- Total = 45 + 72 + 80 = **197 units** (12 se divide karne ka mauka aata hai, yani total = 197/12)

**Step 3 – 1 unit nikalo:**
- Total current income = ₹98,500 = 197/12 units
- 1 unit = 98500 × 12 ÷ 197 = **₹6000** (197 × 500 = 98500, so 500 × 12 = 6000)

**Step 4 – B + C:**
- B + C = 6 + 20/3 = **38/3 units**
- = 38/3 × 6000 = 38 × 2000 = **₹76,000** ✔

**Note:** Ye question tough nahi hai. Fractions ki wajah se daravna lagta hai. Agar numbers whole hote to bahut easy lagta.

## 17. Age Problems

**Concept:** Age ka difference **kabhi nahi badalta**. Time ka gap alag-alag ratio me alag units ke barabar hota hai.

### Question

Mother aur daughter ki present ages ka ratio **7 : 1**. **5 saal baad** ratio **4 : 1** ho jaayega. Unki present ages ka difference?

**Step 1 – Internal gap same karo:**
- Present ratio 7 : 1 → gap = 6
- Future ratio 4 : 1 → gap = 3
- Future ratio ko 2 se multiply: **8 : 2** → gap = 6 ✔

**Step 2 – Subtract (future − present):**
- (8 − 7) : (2 − 1) = **1 : 1**
- 1 unit = **5 years** (kyunki 5 saal baad ka difference)

**Step 3 – Present ages:**
- Mother = 7 × 5 = **35 years**
- Daughter = 1 × 5 = **5 years**
- **Difference = 35 − 5 = 30 years** ✔

## 18. Practice Questions (Solved)

### P1: Teen numbers 1/2 : 2/3 : 3/4 ke ratio me hain. Sabse bade aur sabse chhote ka difference 27 hai. Sabse chhota number?

- LCM(2, 3, 4) = 12 → ratio = **6 : 8 : 9**
- Difference = 9 − 6 = **3 units = 27** → 1 unit = 9
- Sabse chhota = 6 × 9 = **54** ✔

### P2 (Mini concept): Agar 15 units = 45 hain, to 108 units = ?

- 1 unit = 45 ÷ 15 = **3**
- 108 units = 108 × 3 = **324** ✔

### P3: ₹10,500 ko A, B, C me 5 : 7 : 9 me baanta gaya. Har ek ko ₹500 aur mile. Naya ratio?

- **Smart way:** Dono me same ₹500 add ho raha hai, isliye ratio units ke liye 500 = 1 unit hi hai (total 21 units = 10500 → 1 unit = 500). Add 1 unit har ek me:
- 6 : 8 : 10 → simplify (÷2) → **3 : 4 : 5** ✔

(Long way: 2500, 3500, 4500 → +500 → 3000 : 4000 : 5000 = 3 : 4 : 5. Dono same.)

### P4: Galti se ₹702 ko 1/3 : 1/4 : 1/6 ki jagah 3 : 4 : 6 me baanta gaya. Ram, Ramesh, Naresh me sabse zyada fayda kise hua aur kitna?

- Correct ratio: LCM 12 → 1/3 : 1/4 : 1/6 = 4 : 3 : 2
- Galat ratio: 3 : 4 : 6
- Naresh ko sahi me 2 part milne the, galat me 6 mile → **Naresh ko sabse zyada fayda**.
- Sahi share: 702 × 2/9 = **₹156**
- Galat share: 702 × 6/13 = **₹324**
- **Fayda = 324 − 156 = ₹168** ✔

### P5: Do numbers 3 : 4 me hain. Dono me 30 add karne par 9 : 10. Numbers? → **15 aur 20** (Section 14 me solved)

### P6: Classes 3 : 4 : 5 me students. Har class me 20 badhe → 4 : 5 : 6. Original total? → **240** (Section 14 me solved)

### P7: Teen sections 3 : 5 : 8; 15, 30, 15 aur aaye → 4 : 7 : 9. Original total? → **240** (Section 14 me solved)

### P8: A : B income 11 : 13, expenditure 9 : 11, savings ₹4000 each. Income difference? → **₹4000** (Section 15 me solved)

### P9: A, B income 5 : 3; expenditure A : B : C = 8 : 5 : 2; C spends ₹2000, B saves ₹700. A kitna bachata hai? → **₹1500**

### P10: A : B : C ki last year income 3 : 4 : 5; growth ratios 4:5, 2:3, 3:4; total current ₹98,500. B + C? → **₹76,000**

### P11: Mother : Daughter ages 7 : 1; 5 saal baad 4 : 1. Age difference? → **30 years**

## 20. Common Mistakes (Note karke rakho!)

1. **Units alag hain (₹ aur km) aur ratio bana diya** → Galat. Answer "cannot be determined".
2. **Internal gap same kiye bina ratios subtract kar diye** → Galat. Pehle gap same karo.
3. **Ulta-N approach har jagah laga diya** → Sirf chain ratios (A:B, B:C) me lagta hai, A:B aur A:C me nahi.
4. **Alag-alag ratio set ka "1 unit" mix kar diya** (jaise expenditure aur income ke unit) → Har ratio ka apna unit.
5. **Coins me total (₹ ya coins) aur ratio ka type mismatch ignore kiya** → pehle same type me convert karo.
6. **Ratio me fractions chhod diye** → Ratio hamesha whole numbers me hota hai, LCM se multiply karo.
7. **Questions ko jaldi me padhna** ("Total cost of coins ₹55" ko "55 coins" samajh lena) → words dhyan se padho.
