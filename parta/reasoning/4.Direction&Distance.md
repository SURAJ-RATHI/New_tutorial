# 🧭 Directions & Distance — Complete Notes

> Complete beginner-friendly notes based on the lecture.
>
> Covers **all important concepts, question types, shortcuts, formulas, examples, tricks, and practice questions**.

---

# 1. What is Directions & Distance?

The chapter mainly asks us to find:

1. **Direction** — किस दिशा में?
2. **Distance** — कितनी दूरी?

So remember:

```text
Directions & Distance
        ↓
 ┌──────┴──────┐
Direction    Distance
```

Typical questions may ask:

* In which direction is A from B?
* What is the final direction of a person?
* What is the distance between A and B?
* How far is A from B?
* What is the position of B with respect to A?
* What direction is the person facing?
* What is the shortest distance?

---

# 2. Basic Directions

There are **4 main/basic directions**.

| English | Hindi        |
| ------- | ------------ |
| East    | पूर्व / पूरब |
| West    | पश्चिम       |
| North   | उत्तर        |
| South   | दक्षिण       |

On paper, always represent them like this:

```text
                 NORTH
                   ↑
                   |
WEST  ←─────────── ● ───────────→  EAST
                   |
                   ↓
                 SOUTH
```

## ⭐ Most Important

On paper:

```text
          N
          ↑
          |
W  ←──────●──────→  E
          |
          ↓
          S
```

So:

* Right = East
* Left = West
* Up = North
* Down = South

```text
               \  |  /

               /  |  \
              /   |   \
            SW    |    SE
```

They are:

| Direction | Meaning    |

| NE        | North-East |

# 5. How to Remember Directions

Think of yourself standing at the center.

```text
                 FRONT
                   N
                   ↑

LEFT  W  ←────── YOU ──────→  E  RIGHT

                   ↓
                 BACK
                   S
```

If you are facing North:

* Right = East
* Left = West
* Back = South

If you are facing South:

* Right = West
* Left = East
* Back = North

# 6. Clockwise and Anticlockwise

Two important circular movements are:

### Clockwise

Same direction as a clock.

```text
             N
             ↑
             |
      W ←────●────→ E
             |
             ↓
             S

Clockwise:

N → E → S → W → N
```

### Anticlockwise

Opposite direction of a clock.

```text
N → W → S → E → N
```

So memorize:

### Clockwise

```text
N → E → S → W → N
```

### Anticlockwise

```text
N → W → S → E → N
```

---

# 7. Right Turn and Left Turn

A **normal/right-angle turn** means 90°.

## Right Turn

Right turn = **90° clockwise**

Example:

```text
Facing N

        N
        ↑
        |
        ● ─────→ E

Right turn → E
```

Therefore:

```text
90° clockwise = Right turn
```

## Left Turn

Left turn = **90° anticlockwise**

Example:

```text
Facing N

        N
        ↑
        |
        ●
        ←───── W

Left turn → W
```

Therefore:

```text
90° anticlockwise = Left turn
```

---

# 8. Turn Table ⭐

Memorize this table.

| Current Direction | Right Turn | Left Turn |
| ----------------- | ---------- | --------- |
| N                 | E          | W         |
| E                 | S          | N         |
| S                 | W          | E         |
| W                 | N          | S         |

### Example

You are facing East.

Take a right turn.

```text
E → S
```

Answer = **South**

# 9. Opposite Directions

Memorize the opposite pairs.

```text
N ↔ S
E ↔ W

NE ↔ SW
NW ↔ SE
```

Table:

| Direction | Opposite |
| --------- | -------- |
| N         | S        |
| S         | N        |
| E         | W        |
| W         | E        |
| NE        | SW       |
| SW        | NE       |
| NW        | SE       |
| SE        | NW       |

# 10. Turning by Different Angles

The lecture also discusses turns involving angles.

Remember:

```text
90°  = one right/left turn
180° = opposite direction
270° = three 90° turns
360° = complete circle
```

## ⭐ Important

```text
90°  → adjacent direction
180° → opposite direction
270° → opposite of 90° movement
360° → same direction
```

---

# 11. 180° Turn

A 180° turn means you face the opposite direction.

Example:

```text
N → S
E → W
NE → SW
NW → SE
```

### Shortcut

If question says:

> He turns 180°.

Immediately use:

```text
Current direction → Opposite direction
```

---

# 12. 360° Turn

A complete 360° turn brings you back to the same direction.

```text
N → N
E → E
S → S
W → W
```

So:

```text
360° = no change in final direction
```

---

# 13. 45° Turn

A 45° turn does not move from one main direction directly to another main direction.

It creates a diagonal direction.

Example:

If facing North and turn 45° clockwise:

```text
N
 \
  \ 45°
   \
    NE
```

Answer:

```text
North → North-East
```

Similarly:

```text
N + 45° anticlockwise = NW
E + 45° clockwise = SE
E + 45° anticlockwise = NE
S + 45° clockwise = SW
S + 45° anticlockwise = SE
W + 45° clockwise = NW
W + 45° anticlockwise = SW
```

---

# 14. Multiple Turns — Cancellation Trick ⭐

This is one of the most useful shortcuts.

If a person makes:

```text
Right + Left
```

they cancel each other.

Example:

```text
Right → Left
```

Net movement:

```text
0°
```

So the direction remains unchanged.

---

# 15. Two Right Turns

Two consecutive right turns:

```text
Right = 90°
Right = 90°

Total = 180°
```

Therefore:

```text
2 Right Turns = Opposite direction
```

Example:

```text
N
↓
Right → E
Right → S
```

Final = South.

---

# 16. Two Left Turns

Similarly:

```text
2 Left Turns = 180°
```

Therefore, the final direction is opposite.

Example:

```text
N
← Left = W
← Left = S
```

Final = South.

---

# 17. Four Same Turns

Four right turns:

```text
90° + 90° + 90° + 90°
= 360°
```

So:

```text
4 Right Turns = Same direction
```

The same is true for four left turns.

```text
4 Left Turns = Same direction
```

---

# 18. Right + Left Cancellation

Suppose:

```text
Right
Right
Left
Left
```

The two right turns and two left turns cancel.

Net:

```text
0°
```

So final direction = starting direction.

---

# 19. A Very Important Exam Trick

Do **not** automatically add all distances.

First understand what the question asks.

There are two major situations:

### Situation 1 — Total distance travelled

Add every distance.

```text
3 km + 4 km + 5 km
= 12 km
```

### Situation 2 — Shortest distance between starting and final point

You need the final position.

You may need:

* horizontal distance
* vertical distance
* Pythagoras theorem

---

# 20. Type 1 — Find Final Direction

These questions simply ask:

> After all the movements, which direction is the person facing?

Example:

> A person faces North. He turns right, then right again. What direction is he facing?

Solution:

```text
Start = N

Right → E
Right → S
```

Answer:

```text
SOUTH
```

---

# 21. Type 2 — Initial Direction to Final Direction

Example:

> A man starts facing East. He turns left, then right, then right. What direction is he facing?

Solve step-by-step:

```text
Start = E

Left  → N
Right → E
Right → S
```

Final:

```text
SOUTH
```

---

# 22. Type 3 — Final Direction to Initial Direction

Sometimes the question gives the movement and asks what direction the person was initially facing.

Example:

> A person turns right twice and finally faces South. What direction was he initially facing?

Two right turns = 180°.

South's opposite = North.

Therefore:

```text
Initial direction = NORTH
```

---

# 23. Type 4 — Relative Direction

This is one of the most important types.

The question may ask:

> What is the position of B with respect to A?

The key is:

### ALWAYS draw the position of both points first.

Example:

```text
A ─────→ B
```

B is to the **East of A**.

Therefore:

```text
B with respect to A = East
```

---

# 24. "A with Respect to B" Trick ⭐

This wording confuses many students.

Suppose:

```text
A
↑
|
B
```

A is North of B.

Question:

> What is the direction of A with respect to B?

Look:

```text
From B → A
```

Answer:

```text
North
```

---

# 25. "B with Respect to A"

Same diagram:

```text
A
↑
|
B
```

Question:

> What is the direction of B with respect to A?

Start at A and look toward B.

```text
A
↓
B
```

Answer:

```text
South
```

### ⭐ Golden Rule

> **Start from the second-mentioned/reference point and move toward the first-mentioned point.**

For:

```text
A with respect to B
```

Start at:

```text
B
```

Go toward:

```text
A
```

---

# 26. Relative Direction Example

Suppose:

```text
        A
        |
        |
        B
```

Question:

> What is the position of A with respect to B?

Start at B:

```text
B → A
```

Answer:

```text
North
```

Question:

> What is the position of B with respect to A?

Start at A:

```text
A → B
```

Answer:

```text
South
```

# 27. Type 5 — Distance Questions

Distance questions can be divided into:

### A. Total distance travelled

Add all movements.

### B. Shortest distance between two points

Find the straight-line distance.

---

# 28. Total Distance

Example:

A person travels:

```text
3 km
+
4 km
+
5 km
```

Total distance:

```text
3 + 4 + 5 = 12 km
```

Answer:

```text
12 km
```

You do **not** need Pythagoras if the question simply asks total distance travelled.

---

# 29. Lecture Trick — Don't Read the Whole Story

Some exam questions contain a very long story.

For example:

```text
A → 2 km
B → 3 km
C → 4 km
D → 4 km
E → 5 km
```

Question:

> How many kilometres had the person covered when he reached E?

You don't need to solve the whole direction problem.

Just add the distances **up to E**.

```text
2 + 3 + 4 + 4
= 13 km
```

Do NOT include the next 5 km because that is after E.

Answer:

```text
13 km
```

---

# 30. Example — Roundabout Distance

Suppose:

```text
Start
  |
  | 3 km
  ↓
T-point
  |
  | 2 km
  ↓
Roundabout
```

Question:

> How many kilometres did he travel to reach the roundabout?

Simply:

```text
3 + 2 = 5 km
```

Answer:

```text
5 km
```

No direction calculation is needed.

---

# 31. Type 6 — Shortest Distance

Now suppose a person moves:

```text
→ 3 km
↑ 4 km
```

Diagram:

```text
        B
        ●
        |
      4 km
        |
        ●
        |
        └────────●
             3 km
```

Starting point = A

Final point = B.

The shortest distance is the diagonal.

This creates a right-angle triangle.

Use:

```text
a² + b² = c²
```

Therefore:

```text
3² + 4² = c²

9 + 16 = c²

25 = c²

c = 5
```

Answer:

```text
5 km
```

---

# 32. Pythagoras Theorem ⭐

The lecture explains that in Type 4 distance questions, if a triangle is formed, it is a **right-angle triangle**.

Formula:

```text
Hypotenuse² = Base² + Height²
```

or:

```text
c² = a² + b²
```

Therefore:

```text
c = √(a² + b²)
```

---

# 33. Pythagorean Triplets

You should memorize common triplets.

## Most important:

```text
3 - 4 - 5
```

Because:

```text
3² + 4² = 5²
9 + 16 = 25
```

---

# 34. Second Important Triplet

```text
5 - 12 - 13
```

Because:

```text
5² + 12² = 13²
25 + 144 = 169
```

---

# 35. Multiples of 3-4-5

If:

```text
3 - 4 - 5
```

then multiply everything by the same number.

For example ×2:

```text
6 - 8 - 10
```

×3:

```text
9 - 12 - 15
```

×4:

```text
12 - 16 - 20
```

So:

```text
3,4,5
6,8,10
9,12,15
12,16,20
...
```

These can save time in exams.

---

# 36. Important Triplets to Memorize

```text
3 - 4 - 5
5 - 12 - 13
6 - 8 - 10
9 - 12 - 15
12 - 16 - 20
```

The lecture emphasizes that the **3-4-5 and 5-12-13 triplets** are particularly useful for reasoning questions.

---

# 37. Even Number Triplet Formula

The lecture also discusses a formula for generating Pythagorean triplets from an even number.

If the even number is:

```text
n
```

then the other two numbers can be generated as:

```text
(n² / 4) - 1
(n² / 4) + 1
```

So:

```text
n = 4
```

Then:

```text
4² / 4 = 4
```

Other values:

```text
4 - 1 = 3
4 + 1 = 5
```

Therefore:

```text
3 - 4 - 5
```

For:

```text
n = 12
```

You can generate:

```text
12
(12² / 4) - 1
(12² / 4) + 1
```

which gives:

```text
5 - 12 - 13
```

# 38. Type 7 — Direction + Distance Together

These questions combine:

* movement
* turns
* direction
* distance

Example:

> A person travels 12 km East. He then turns left and travels 5 km. Find the shortest distance from the starting point.

Draw:

```text
                 B
                 ●
                 |
                 | 5 km
                 |
A ●──────────────●
       12 km
```

Horizontal = 12 km

Vertical = 5 km

Shortest distance:

```text
√(12² + 5²)
= √(144 + 25)
= √169
= 13 km
```

Answer:

```text
13 km
```

---

# 39. Direction of the Final Point

In the above example:

```text
Start → East
Then → North
```

So final point is:

```text
North-East
```

Therefore:

```text
Shortest distance = 13 km
Direction = NE
```

The lecture uses such questions to test the final facing direction.

# 41. Direction-Only Shortcut

Suppose:

```text
Start = North

Right
Right
Right
Left
```

Track only directions:

```text
N
↓ Right → E
↓ Right → S
↓ Right → W
↓ Left  → S
```

Final direction:

```text
South
```

No distance calculation required.

---

# 42. When Distance is Irrelevant

If question asks:

> What direction is the person facing?

and gives:

```text
10 km
20 km
50 km
30 km
```

The actual distances may not matter.

Only the turns matter.

### Remember:

```text
Direction question → focus on turns
Distance question → focus on distances
Shortest distance → calculate position
```

# 43. Type 9 — Roundabout Questions ⭐

Roundabouts are common and can confuse students.

A roundabout may have:

* 3 roads
* 4 roads
* multiple exits

The lecture specifically discusses **second left/right at a roundabout**.

---

# 44. "Second Left" Does NOT Mean Two Left Turns

This is extremely important.

If the question says:

> Take the second left at the roundabout.

It does **not** mean:

```text
Left + Left
```

Instead:

```text
First left = ignore
Second left = take
```

Example:

```text
              Road
                |
                |
       Road ─── O ─── Road
                |
                |
              Road
```

At the roundabout:

```text
1st left → ignore
2nd left → take
```

---

# 45. Four-Road Roundabout

At a four-road roundabout, taking the **second left** can effectively take you to the opposite road.

So:

```text
Second Left
```

at a four-road roundabout can mean:

```text
Opposite direction
```

This is why you must draw the roundabout if confused.

---

# 46. Example — Second Left

Suppose a person reaches a four-road roundabout while facing North.

He takes the second left.

At the roundabout:

```text
First left → West
Second left → South
```

Therefore:

```text
Final direction = South
```

### Shortcut

At a 4-road roundabout:

```text
1st left  = left direction
2nd left  = opposite direction
3rd left  = right direction
```

Similarly:

```text
1st right  = right direction
2nd right  = opposite direction
3rd right  = left direction
```

---

# 47. Roundabout Shortcut Table

If facing North:

| Exit      | Direction |
| --------- | --------- |
| 1st Left  | West      |
| 2nd Left  | South     |
| 3rd Left  | East      |
| 1st Right | East      |
| 2nd Right | South     |
| 3rd Right | West      |

The exact interpretation depends on the road layout, so **draw the roundabout when the wording is ambiguous**.

---

# 48. Roundabout Distance Trick

Sometimes a question asks:

> After taking the second left at the roundabout, how much distance does he travel before reaching home?

You don't need to solve the complete story.

Find the roundabout.

Then count only the distances travelled **after the roundabout**.

Example:

```text
Roundabout
    |
    | 1 km
    ↓
Point A
    |
    | 3 km
    ↓
Point B
    |
    | 2 km
    ↓
Home
```

Total after roundabout:

```text
1 + 3 + 2 = 6 km
```

Answer:

```text
6 km
```

# 49. T-Point / T-Junction

A T-point looks like:

```text
─────────────
      |
      |
      |
```

or:

```text
      |
      |
──────┴──────
```

At a T-point, there may be fewer choices than at a four-road intersection.

### Important

Always understand:

* which road you are coming from
* which direction you are facing
* whether the turn is left or right

# 50. Chauraha / Four-Way Junction

A four-way intersection has four roads.

```text
        |
        |
────────●────────
        |
        |
```

This is different from a T-point.

At a four-way junction:

```text
Left
Straight
Right
```

are normally possible.

# 51. Type 10 — Position of Multiple Points

These questions give relationships between points.

Example:

> B is east of A.
> D is south of B.
> C is west of B.
> E is south of C.
> Find the direction of A with respect to E.

Draw the points:

```text
          A
          |
          |
          B
        /   \
       C     ...
       |
       |
       E
```

Then identify the direction from E to A.

The lecture's example gives:

```text
A is North of E
```

So answer:

```text
NORTH
```

---

# 52. How to Solve Point-Relationship Questions

Use this method:

### Step 1

Write the first relationship.

### Step 2

Place the next point.

### Step 3

Continue connecting all points.

### Step 4

Identify the two points asked in the question.

### Step 5

Draw an imaginary arrow from the reference point to the required point.

### Step 6

Read the direction.

---

# 53. Example

Given:

```text
B is East of A.
D is South of B.
C is West of B.
E is South of C.
```

Draw:

```text
A ───── B
       |
       |
       D

C is west of B:

C ───── B

E is south of C:

C
|
|
E
```

Now compare A and E.

```text
A
|
|
C
|
|
E
```

Therefore:

```text
A is North of E.
```

# 54. Type 11 — Shadow Questions ⭐

Shadow questions depend on the position of the Sun.

Basic idea:

```text
Sun → Shadow is in opposite direction
```

So if you know the Sun's direction, the shadow is opposite.

---

# 55. Basic Sun Direction

The Sun:

```text
rises in East
sets in West
```

Therefore:

### Morning

Sun is generally in the East.

So:

```text
Shadow → West
```

### Evening

Sun is generally in the West.

So:

```text
Shadow → East
```

---

# 56. Shadow Shortcut

Remember:

```text
Sun direction ↔ Shadow direction
       opposite
```

Examples:

```text
Sun East  → Shadow West
Sun West  → Shadow East
Sun North → Shadow South
Sun South → Shadow North
```

---

# 57. Person + Shadow

Example:

> A person is standing with his shadow towards the West. In which direction is the Sun?

Shadow = West.

Sun = opposite.

Therefore:

```text
Sun = East
```

---

# 58. Person Facing Shadow

Example:

> In the morning, a person sees his shadow towards his left. Which direction is he facing?

Morning:

```text
Sun = East
Shadow = West
```

The person's left side is West.

Which direction has West on its left?

If facing South:

```text
          S
          ↓
     E ← PERSON → W
```

Actually, when facing South:

```text
Left = East
Right = West
```

Therefore West is on the right, not left.

If facing North:

```text
Left = West
Right = East
```

Therefore:

```text
Person = North
```

### Important

Always draw the person-facing diagram rather than guessing.

---

# 59. Shadow Questions — Golden Rule

Do not memorize too many separate cases.

Use:

```text
1. Find Sun direction.
2. Shadow is opposite Sun.
3. Relate shadow to person's left/right/front/back.
4. Find person's direction.
```

---

# 60. Type 12 — Upside-Down Person

Some questions describe a person being turned upside down or changing orientation.

The important idea is:

### Do not confuse the person's physical position with the direction of movement/facing.

If the question asks:

> Which direction is his head/face/feet?

Draw the person and use the stated orientation.

---

# 61. Upside-Down Trick

If a person turns completely upside down:

```text
Head ↔ Feet
```

So the relationship reverses.

For example:

```text
Normal:

Head
 ↑
 |
Body
 |
 ↓
Feet
```

Upside-down:

```text
Feet
 ↑
 |
Body
 |
 ↓
Head
```

Always read exactly what the question asks:

* head direction
* feet direction
* face direction
* movement direction

---

# 62. Type 13 — Train + Smoke + Wind

These questions combine direction concepts with a train.

Two important things:

1. Train's movement direction.
2. Smoke's direction.

Smoke can be affected by wind.

### Important idea

If wind direction is given, use it.

For example:

```text
Train → East
Wind → West
```

The smoke direction depends on the wind information given in the question.

Do not automatically assume:

```text
Smoke = opposite train direction
```

unless the question's conditions support it.

---

# 63. Train Question Strategy

Read carefully:

### If asking train direction:

Focus on:

```text
engine / movement / destination
```

### If asking smoke direction:

Focus on:

```text
wind direction
```

### If asking relative direction:

Draw:

```text
Train
Wind
Smoke
```

and determine the required relationship.

# 64. Type 14 — Coded Direction

Some questions use symbols or codes instead of directly saying:

# 70. Type 18 — Mixed Direction + Distance

# 74. Super Shortcut — Number the Directions

For fast solving, you can think:

```text
       N = 0
       E = 1
       S = 2
       W = 3
```

```text
+1
```


```text
+2
```

```text

```

because:

```text

```

```text

```

which is South.

```text

```

which is North again.

This is an optional speed trick.

# 75. Important Distance Formula

When horizontal and vertical distances are known:

```text
Shortest distance
= √(Horizontal² + Vertical²)
```

Example:

```text
Horizontal = 8
Vertical = 6
```

Then:

```text
Distance = √(8² + 6²)
         = √(64 + 36)
         = √100
         = 10
```

Answer:

```text
10 units
```

# 79. Total Distance vs Shortest Distance ⭐⭐⭐

This is one of the biggest exam traps.

Suppose a person travels:

```text
3 km East
4 km North
```

### Total distance:

```text
3 + 4 = 7 km
```

### Shortest distance:

```text
√(3² + 4²)
= 5 km
```

Therefore:

```text
Total distance = 7 km
Shortest distance = 5 km
```

Never confuse these two.

# 84. Common Exam Mistakes

### ❌ Mistake 1

Confusing East and West.

Remember:

```text
W ← ● → E
```

---

### ❌ Mistake 2

Confusing left/right after changing direction.

Your left/right changes depending on which way you are facing.

---

### ❌ Mistake 3

Adding distances when shortest distance is asked.

Wrong:

```text
3 + 4 = 7
```

Correct shortest distance:

```text
√(3² + 4²) = 5
```

---

### ❌ Mistake 4

Thinking second left = two left turns.

Wrong.

```text
Second left = skip first left and take second left.
```

---

### ❌ Mistake 5

Starting from the wrong point.

For:

```text
A with respect to B
```

start from:

```text
B
```

---

### ❌ Mistake 6

Calculating distances when only direction is asked.

Ignore unnecessary numbers.

---

### ❌ Mistake 7

Calculating direction when only total distance is asked.

Simply add the required distances.
