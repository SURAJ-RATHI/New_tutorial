# 🔐 Coding–Decoding: Every Trick Explained Like You're 5

> Coding–Decoding = **secret messages**. Someone changes a word into a secret word (or number), and you must find the rule they used. Reasoning exams usually give **4–6 questions** from this chapter.

There are **3 big families**:

| Family | What changes | Example |
|---|---|---|
| **Letter Coding** | word → another word | `HAND → IBOE` |
| **Number Coding** | word → numbers | `TO → 35` |
| **Mixed Coding** | words/sentences → codes or symbols | `red apple = ka mo` |

---

## 🧰 PART 0 — Your Toolbox (learn this FIRST!)

Without this, nothing works. Think of it as learning to count before doing maths.

### A. Letter places (positions)

```
A=1  B=2  C=3  D=4  E=5  F=6  G=7  H=8  I=9  J=10 K=11 L=12 M=13
N=14 O=15 P=16 Q=17 R=18 S=19 T=20 U=21 V=22 W=23 X=24 Y=25 Z=26
```

### B. Opposite letters (the alphabet folded in half like a book)

A is first, Z is last → they're **opposites**. B and Y are opposites… and so on.

```
A↔Z  B↔Y  C↔X  D↔W  E↔V  F↔U  G↔T
H↔S  I↔R  J↔Q  K↔P  L↔O  M↔N
```

**Teacher's story to remember them:**
**AZ, BY, C-X, D-W, E-vening (EV), F-4 (FU), G-T Road (GT), H-igh S-chool (HS), I-ndian R-ailway (IR), J-ungle Q-ueen (JQ), K-anpur (KP), L-ove (LO), M-a-N (MN)**

> 🧮 **Magic rule:** a letter's place + its opposite's place **always = 27**.
> Example: D(4) + W(23) = 27 ✅. So opposite place = `27 − place`.

### C. Going past the ends (the alphabet is a circle 🔄)

- Go **past Z** → subtract 26. (`28` → `2` → B)
- Go **below A** → add 26. (`−2` → `24` → X)
- `−4` and `+22` give the **same** letter (because 26 − 4 = 22).

**Example:** `X + 3` → 24 + 3 = 27 → 27 − 26 = **1 = A**. So `XYZ + 3 = ABC`.

# 🅰️ PART 1 — LETTER CODING (7 patterns)

### 🧭 Which pattern to try first? (the order matters!)

1. **Quick ones (10–15 seconds):** Position-based → Opposite letters → Common coding.
2. If none of those, you must **add/subtract**. Try in this order: **Forward → Reverse → Cross.**
3. Still stuck? Try the **special / illogical** ones.

**Secret weapon:** Turn every letter into its **place number**, then look at the gaps between the old and new numbers. You are hunting for a **logical sequence** (like +3, +3, +3… or +2, −3, +2, −3…). If the gaps look like a mess (−1, +8, −2, +7), that pattern is wrong — try the next one.

> If two patterns both work, pick **Forward first, then Reverse, then Cross**.

---

## Pattern 1️⃣ — FORWARD (Seedha Kram)

**🧸 Like you're 5:** Kids line up. Kid #1 goes to the new line's spot #1, kid #2 goes to spot #2, and so on. Nobody changes seats. Each letter just takes a little **jump** (a plus or minus).

**🔍 How to know it works:** Write place numbers: 1st old letter vs 1st new letter, 2nd vs 2nd… If the jumps make a **neat pattern**, it's Forward. Neat patterns include:
- same jump: `+1 +1 +1`
- alternating: `+2 −3 +2 −3`
- growing: `+1 +2 +3 +4`
- prime numbers: `+2 +3 +5 +7 +11`
- shrinking: `+10 +9 +8 +7`

**🛠 Steps:** (1) Write places. (2) Find each jump, 1st→1st, 2nd→2nd. (3) Spot the pattern. (4) Apply it to the new word.

**✅ Example:** `HAND → IBOE`
H(8)→I(9) = +1, A(1)→B(2) = +1, N(14)→O(15) = +1, D(4)→E(5) = +1.
Rule: **+1 each**. So `SILK → TJML`.

*Another (growing jumps):* `CAR` with `+1, +2, +3` → C→D, A→C, R(18)+3=21→U → **DCU**.

---

## Pattern 2️⃣ — REVERSE (Ulta Kram)

**🧸 Like you're 5:** The kids line up **backwards**. The last kid in the old line goes to the front of the new line. *Then* each kid also takes a small jump.

**🔍 How to know it works:** Forward gives a **messy** jump list. So you compare **1st old with LAST new**, **2nd old with 2nd-LAST new**, etc. If *that* gives a neat pattern → Reverse.

**🛠 Steps:** (1) Flip the new word's order. (2) Compare place numbers. (3) Find the pattern. (4) Apply the same flipped matching to the new word.

**✅ Example:** `PERSON → LMQPCN`
Old: P E R S O N. New backwards: N C P Q M L.
P(16)→N(14) = −2, E(5)→C(3) = −2, R(18)→P(16) = −2 … every jump is **−2**, but **in reverse order**.
Now code `WORLD`: reversed = D L R O W, each −2 → B J P M U → **BJPMU**.

---

## Pattern 3️⃣ — CROSS (Tirchha Kram)

**🧸 Like you're 5:** The kids **swap seats in a funny way** — maybe in pairs, maybe in threes, maybe a mix of forward and backwards. Harder to see, so you try it **last**.

**🔍 How to know it works:** Forward ❌ and Reverse ❌ both give messy gaps. That means the letters are probably crossed. Try pairs (1↔2, 3↔4…), groups of 3, or "odd seat" shuffles. It appears **least often in exams**, but has many versions. Odd-length words can be crossed too!

**🛠 Steps:** (1) Fail Forward. (2) Fail Reverse. (3) Try pairing neighbours / distant letters until one set of gaps becomes neat.

**✅ Example:** `FISH → JGIT`
Swap in pairs → I F H S. Now each letter is **+1**: I→J, F→G, H→I, S→T → **JGIT**.
(Notice the code's 1st letter J comes from the word's 2nd letter I.)

---

## Pattern 4️⃣ — POSITION-BASED (Jumbling)

**🧸 Like you're 5:** Same toys, **new order**. Nothing is added, nothing is taken. You're just shuffling a deck of cards.

**🔍 How to know it works (10 seconds!):** Look at both words: **do they use exactly the same letters?** Yes → Position-based. No plus or minus needed. The only job: find *how* they were shuffled.

**The 6 shuffles you may see:**

| # | Shuffle | Old → New |
|---|---|---|
| a | **Full reverse** | `MOTHERS → SREHTOM` |
| b | **Pairs flipped** (last pair may stay – *don't "fix" it, it's on purpose!*) | `PO LI TI CS → OP IL IT CS` = `OPILITCS` |
| c | **Groups of 2, 3, 4 flipped** | `MA\|THE\|MATI\|CS → AM\|EHT\|ITAM\|CS` = `AMEHTITAMCS` |
| d | **Cut in half, flip each half** | `PLA\|YER → ALP\|REY` = `ALPREY` |
| e | **Pairs placed in a random order** | `MO NK EY` → (pair 2, pair 3, pair 1) → `NKEYMO` |
| f | **Alphabetical order** (sometimes vowels first, then consonants) | `MOTHER → EOHMRT` (vowels E, O first; then H, M, R, T) |

**Trick for (e):** note *which pair goes where* in the first word, then repeat the exact same moves on the second word.
**Trick for (f):** if no simple flip works and options all start with different letters, try sorting A→Z.

**✅ Example (e):** `BANDIT → ?` suppose `MONKEY → NKEYMO` (pair-2, pair-3, pair-1). `BA ND IT` → `ND IT BA` = **NDITBA**.

---

## Pattern 5️⃣ — OPPOSITE LETTERS

**🧸 Like you're 5:** Look in a **mirror**. A sees Z, B sees Y. Each letter becomes its mirror twin.

**🔍 How to know it works:** If the places of old and new letters **add up to 27** (or 25 — see twist), it's opposite letters. Teacher says this takes only **2–4 seconds** once you know the AZ-BY chart.

**🛠 Steps:** Swap every letter for its mirror twin.

**✅ Example:** `BAD → YZW` (B↔Y, A↔Z, D↔W).

**🌀 Twist:** If places add up to **25**, it's *opposite then −2*. Check: H(8) → opposite S(19) → −2 → Q(17). And 8 + 17 = 25 ✅. So `HI → QP`.
(If the question has **sum 27 + "opposite −2"**, both views give the same answer — use whichever is easier.)

---

## Pattern 6️⃣ — COMMON CODING (No logic at all!)

**🧸 Like you're 5:** Nicknames. Your friend "Pinky" is **always** called Pinky, in every game. No rule needed — just remember who is who.

**🔍 How to know it works:** The question gives **a few words/codes**, and the thing you must find uses **only letters/symbols that already appeared**. No brand-new letters. Under each old letter, whatever sits there **is** its code.

**🛠 Steps:** Match the same letter to the same symbol. A leftover letter goes with the leftover symbol.

**✅ Example (symbols):** `KING = $ @ % #` and `GAIN = % ... ` — simplest form: if `K → $`, `I → @`, `N → %`, `G → #`, then `GIN = # @ %`.

**✅ Example (numbers, jumbled order):**
`TEAR = 4 5 6 7` and `BEAR = 8 5 6 7`.
Common letters E, A, R share common numbers 5, 6, 7. So the leftover letter **T = 4** and **B = 8**.

> ⚠️ Letters in the code may appear in **jumbled order** — so you can know *the group* (E,A,R = 5,6,7) without knowing the exact match.

---

## Pattern 7️⃣ — ILLOGICAL (Old pattern, rare now)

**🧸 Like you're 5:** The rule isn't about alphabet maths. It's about **what words mean**: opposites, directions, months, days, roman numbers.

**🔍 How to know it works:** The alphabet maths gives nonsense, but the **jumbled codes look like real words** when read backwards, or the words are **opposites/related things**.

**Types the teacher showed:**

| Idea | Example |
|---|---|
| **Words read backwards** | `TSAE = EAST`, `TSEW = WEST` → so `SOUTH = HTUOS` |
| **Opposite-word chain** | Early → Late, Cold → Hot (then jumble the opposite) |
| **Roman numbers** | I=1, V=5, X=10, L=50, C=100, D=500, M=1000 |
| **Months / Days** | Letters follow the order Jan, Feb, Mar… or Mon, Tue… |
| **Counting** | 1, 2, 3 … 10 → "T for 10" |

**✅ Example:** If `TSAE` = EAST and `TSEW` = WEST, what is the code for **NORTH**? Write it backwards → **HTRON**.

## 🎁 Special / Tricky Letter Questions (the starred ones ⭐)

These looked impossible in the exam, but each has a clear idea:

**1. Consonant/Vowel split**
Consonants **+3**, vowels **−3**.
✅ `CODE`: C(3)+3=F, O(15)−3=L, D(4)+3=G, E(5)−3=B → **FLGB**.

**2. Sort first, then do maths** (this was a "5-star" question nobody solved!)
Rewrite the word's letters in **A→Z order**, *then* apply a rule.
✅ `DOCTORS` → sorted: C D O O R S T → places 3, 4, 15, 15, 18, 19, 20.
Rule **+3, −3, +3, −3…** → 6, 1, 18, 12, 21, 16, 23 → **FARLUPW**.
*How to know:* the code doesn't match any normal pattern, but if the word's letters are sorted, a neat +/− pattern appears.

**3. Prime-number gaps in the sorted letters**
`TEACHER` sorted: A C E E H R T → places 1, 3, 5, 5, 8, 18, 20. Gaps between letters... In the series version the code gaps were 2, 3, 5, 7, 11 (prime numbers!). Next after 7 is **11** (not 9!).
✅ Series `A, C, F, K, R, ?` → gaps +2, +3, +5, +7, **+11** → 18 + 11 = 29 → 29 − 26 = 3 → **C**.

**4. Add the digits of a two-digit place**
`19 → 1+9 = 10`, `20 → 2+0 = 2`; single digits stay as they are.
✅ `TOP`: T(20)→2→B, O(15)→1+5=6→F, P(16)→1+6=7→G → **BFG**.

**5. Double digit sum rule trick:** place 18 → 1+8 = 9 = I, place 26 → 2+6 = 8 = H, etc. — always convert to **letters again** if the answer is a letter code.

## 🧩 Question FORMS you'll see in the exam

The same codes dress up in 4 outfits:

### 1. Normal
"`TEMPLE` is coded `RMGVGO`. What is the code for `PEOPLE`?" → find the pattern, apply it.

### 2. Analogy
"In a language `CAT : DBU`. In the same way `DOG : ?`"
CAT → +1 each → DBU. DOG → **EPH**.

### 3. Classification (Odd One Out)
**Compare the letters inside each option.** Find the jump pattern that 3 options share.
✅ `DG, EH, FI, GK` → D→G (+3), E→H (+3), F→I (+3), G→K (**+4**) → **GK is the odd one**.
*Tip:* the relation may be 1st–2nd letter, or 1st–3rd letter. Try more than one.

### 4. Series
**1st letters compare with 1st letters, 2nd with 2nd, 3rd with 3rd…** (don't compare neighbours like in classification!)
✅ `AC, BD, CE, ?` → 1st letters A,B,C → D. 2nd letters C,D,E → F. Answer **DF**.

# 🔢 PART 2 — NUMBER CODING (2 types)

## 🔎 How to tell which type

- **The whole word becomes ONE number** → **Type 1**
  (`TO = 35`)
- **Every letter gets its OWN number** → **Type 2**
  (`BEAD = 5 31 19 25` style lists)

---

## ✳️ TYPE 1 — Word → ONE number (9 rules)

**🧸 Like you're 5:** The word is turned into a **score**, like points in a game. You must find how the score is counted.

### 🧭 Order to try (very important)

1. **Count letters / vowels / consonants** (no alphabet needed — super easy)
2. **Add the places of the letters** (then maybe do extra maths)
3. If still nothing, **add the OPPOSITE places** (hardest — takes the most time)

### Rule list

**Step 1 — Counting rules (no alphabet needed)**

| Idea | Example |
|---|---|
| **Total letters** itself | `CAT = 3` |
| **Total letters squared / cubed / ×5** | `TO=4, SUN=9, GAME=16` → `PLANT = 25`; cube: 4 letters → 64 |
| **Vowels count then consonants count** | `TOM` (1 vowel, 2 consonants) = **12**; `CHAIR` = 2 vowels, 3 consonants = **23** |

**Step 2 — Add the places (4 versions)**

| Version | How it works | Example |
|---|---|---|
| **Plain sum** | add places | `TO` = 20+15 = **35** |
| **Sum, then ×, ÷** | sum then multiply/divide | `BAD`: 2+1+4 = 7 → ×2 = **14** |
| **Sum, then + or −** | sum then add/subtract something | `CAT`: 24, then +2 = **26** |
| **Digit-sum version** | break 2-digit places into digits and add all | `BAT`: B=2, A=1, T=20→2+0 → 2+1+2+0 = **5** |

**Step 3 — Same four versions, but with OPPOSITE places**

`BAD` → opposites Y(25) + Z(26) + W(23) = **74**.
The same extra maths can follow (e.g., `+ total letters`: 74 + 3 = **77**).

### 🕵️ The "extra" number: constant or logic?

When the extra number added/subtracted **is the same for every word** (like +2 always) → it's a **constant**.
When it **changes with the word** (2 for a 2-letter word, 3 for a 3-letter word) → it's **logic**: usually the **total number of letters**, **vowels**, or **consonants**.

### ✅ Full example

> `GAME = 20`? Let's practice on `CAT = 24` and `SAD = 24`.
> C(3)+A(1)+T(20) = 24 ✅. S(19)+A(1)+D(4) = 24 ✅.
> Rule: **plain place-sum**. Then `SHE` = 19+8+5 = **32**.

### ✅ Opposite-letter example (the sneaky one)

If `KANPUR`-type words give odd numbers, convert to opposites first: each word's opposite-place sum, **plus total letters**.
E.g. rule "opposite-sum + number of letters": `BAD` → 74 + 3 = **77**.
*Teacher's warning:* this type **wastes exam time** because you fail 2–3 rules first. Practise it so you see it fast.

> 💡 Exam tip: **options help!** Often you can reject 3 options quickly just by checking the last digit.

---

## ✳️ TYPE 2 — Each letter gets its OWN number

**🧸 Like you're 5:** Each toy gets its own sticker number. Easy, because there's no adding of the whole word.

**🔍 How to know:** The coded answer is a **list of numbers**, with one entry per letter. Always start by writing each letter's place number, then compare.

### Common Type 2 rules

| Rule | Example |
|---|---|
| **Double + 1** | place ×2 + 1: `B(2)→5`, `O(15)→31` |
| **Squares** | `CAB → 9, 1, 4` (3², 1², 2²) |
| **Opposite letter's place** | `DAY` → W, Z, B → **23, 26, 2** |
| **×1, ×2, ×3, ×4…** (growing multiplier) | `PLAY` → 16×1, 12×2, 1×3, 25×4 = **16, 24, 3, 100** |
| **Digit sum** of the place | `TO` → 2, 6 (T=20→2, O=15→6) |
| **Vowels → 1 to 5, consonants → next letter** | A=1, E=2, I=3, O=4, U=5 (vowel's order number!) |
| **Meaning-based opposites** | `BLACK`'s opposite = `WHITE` → W,H,I,T,E = 23 8 9 20 5. So `DARK` → opposite `LIGHT` = 12 9 7 8 20 |
| **Common coding** with numbers | same letter, same number |

**⚠️ "Hidden squares" warning:** if the code looks like `256 144 1 625`, ask "is this a perfect square?" 256 = 16², 144 = 12², 1 = 1², 625 = 25² → P, L, A, Y. If the question says them as `16², 12²…` it's easy — if hidden, you must **notice** squares.

### ✅ Examples

- **Consonant +1, vowel → number:** `BAKE` → B→C, A→1, K→L, E→2 → **C 1 L 2**.
- **Growing multiplier:** `CAB` → 3×1, 1×2, 2×3 → **3 2 6**.
- **Opposites by meaning:** if `BLACK = 23 8 9 20 5`, then `DARK = 12 9 7 8 20`.

# 🔀 PART 3 — MIXED CODING (2 patterns)

## 🅰️ OLD PATTERN — "Chinese / Japanese Coding" (the easiest!)

**🧸 Like you're 5:** Imagine foreign words. You have no dictionary, but if the word "**ball**" shows up in two sentences, the **same foreign word** must show up in both translations. That's it!

**🔍 How to know it works:** You see 2–4 **sentences** with codes (words or numbers), and the asked word **already appears** in the sentences.

**🛠 Steps:**
1. Compare **Sentence 1 with Sentence 2** → find the common word on the left AND the common code on the right → they match.
2. Compare **1 with 3**, then **2 with 3** (and with 4 if present).
3. Whatever word is **left over** matches whatever code is **left over**.
4. Look at the **options**.

**✅ Example:**
`red apple = mo ka`, `red car = ka ti`
Common word **red** ⇔ common code **ka**. So `apple = mo`, `car = ti`.
(Code order is jumbled — that's fine!)

### 🔥 Special cases the teacher warned about

- **Not enough info → "can't be determined"**
  If *he is poor = nik pik* and *she is rich = pik vik jik*, you only know `is = pik`. For `he` it could be `nik` **or** something else. The answer depends on the **options**.
- **Pick the option that fits all constraints.** (e.g. "one number must be 8 or 9, one must be 4 or 5, and one must be a brand-new number.")
- **New word → new code.** A word you haven't seen can only match a code you haven't seen.
- **Don't copy answers between questions.** What you found in Q1 doesn't carry to Q2.

### 🔥 "If red is called yellow…" (Substitution)

**Like you're 5:** Names get swapped! Answer using the **swapped name**.
✅ `If red is called yellow, yellow is called blue, blue is called orange, orange is called green, green is called red — what is the colour of a clear sky?`
Sky is **blue**, and **blue is called orange** → **Orange**.
✅ `Sun is moon, moon is water, water is fire, fire is Mars, Mars is Sun — where does a fish live?`
Fish lives in **water**, and water is called **fire** → **Fire**.
*Rule:* find the real thing → look up its **new name** one step.

## 🅱️ NEW PATTERN — Hidden logic

**🧸 Like you're 5:** Every word has **body parts**: a head (first letter), a tail (last letter), a size (total letters), a belly (middle letters). The code is made by choosing some of these parts and doing a tiny change to them.

**🔍 How to know it works:**
- The words in the question have **no common words**, or the asked word isn't there.
- The code looks like a **mix** like `S3Z`, `#4K`, `9O`, `E5`.

### 🕵️ Detective checklist: what parts could be used?

Look at each **code piece**:

| If the code piece is… | It probably comes from… |
|---|---|
| A **number** like 3, 4, 5 | **Total letters** (maybe ±1 or ±2), or **vowel/consonant count**, or a **place number** |
| A **letter** | **First letter**, **last letter**, **2nd-last**, **3rd letter** — maybe ±1 or the opposite |
| A **symbol** (`@`, `#`, `%`) | Chosen by the **first letter**, or by **odd/even** total letters |

**Pro tricks from the teacher:**
1. **Use the hint!** If a word like "**the**" appears twice, its code piece is common. You learn how a 3-letter word with the same 1st letter behaves.
2. **Same symbol for two words?** Look at what they share: same **first letter**? Both **odd** (or both **even**) length?
3. **Symbols tied to first letter:** all words starting with S use `#`, all starting with T use `@`, etc.
4. **Symbols tied to odd/even:** odd letters → `*`, even letters → `%`.
5. **Opposite-letter hint:** if the number is 22 and the letter is V, think "V is the opposite of **E**".

### ✅ Examples

**1. First −1, total −1, last +1**
`BOOK` → B−1 = **A**, 4 − 1 = **3**, K+1 = **L** → **A3L**.

**2. Symbol by first letter + total letters + last letter**
Rule: S → `#`, T → `@`. `SING` → `#4G`, `TALK` → `@4K`, `SOUP` → **`#4P`**.

**3. 3rd letter's place + (2nd-last letter +1)**
`BRAIN`: 3rd letter A → **1**. 2nd-last letter I → +1 → **J**. Code: **1J**.

**4. Symbol by odd/even + first letter's place**
Rule: odd length → `*`, even length → `%`; then first letter's place. `CAT` → `*3`, `DOOR` → `%4`.

**5. Total + 2 and vowels reversed** (invented rule, same idea)
`RADIO`: total 5 + 2 = 7; vowels A, I, O reversed → O, I, A → **7OIA**.

> The teacher said: **NEW pattern questions are the ones in Bank PO / modern SSC**. Make sure you know them.

# 💻 PART 4 — BINARY CODING (Machine Coding)

**🧸 Like you're 5:** A computer has only **light switches: ON (1) or OFF (0)**. It can't say "13". It says "ON, ON, OFF, ON" = `1101`. That's the same number in switch-language.

**🔍 How to know it works:** You see 0s and 1s, or symbols like `*` and `.` that stand for 1 and 0, or the question says "machine / binary".

### 🛠 The Doubling Chart (all you need!)

Write numbers by **doubling**, starting from 1 on the **right**:

```
 64   32   16    8    4    2    1
```

### Decimal → Binary (switch ON the numbers you need)

**✅ Example: 13**
8 + 4 + 1 = 13 → switch **ON** 8, 4, 1; **OFF** 2.

```
 8  4  2  1
 1  1  0  1   →  1101
```

More examples: `12 = 8+4 → 1100`, `3 = 2+1 → 11`, `7 = 4+2+1 → 111`, `21 = 16+4+1 → 10101`.

### Binary → Decimal (add up the switches that are ON)

**✅ Example: 111011**
Chart: 32 16 8 4 2 1 → ON are 32, 16, 8, 2, 1 → 32+16+8+2+1 = **59**.
`111001` → 32+16+8+1 = **57**.

### 📝 Exam-style example

`0 = .`, `1 = *`, `2 = *.`, `3 = **`, `4 = *..` … and so on (`*` is 1, `.` is 0).
**What is the product of `***` and `**`?**
- `***` = 111 = 4+2+1 = **7**
- `**` = 11 = 2+1 = **3**
- 7 × 3 = **21**
- 21 in binary = 10101 → `*.*.*`
**Answer: `*.*.*`**

# 🏁 MASTER CHEAT SHEET — "What do I do when I see a question?"

```
START
  │
  ├─ Letters → Letters?
  │     ├─ Same letters, just shuffled?  ──► POSITION-BASED
  │     ├─ Places add to 27 (or 25)?     ──► OPPOSITE LETTERS
  │     ├─ Only old letters/symbols?     ──► COMMON CODING
  │     └─ Otherwise → write places and check jumps:
  │           ├─ 1st→1st neat?   ──► FORWARD
  │           ├─ 1st→last neat?  ──► REVERSE
  │           ├─ neither?        ──► CROSS
  │           └─ nothing works?  ──► SORT A→Z first, or meaning-based (ILLOGICAL)
  │
  ├─ Word → Number?
  │     ├─ Whole word = ONE number  ──► TYPE 1
  │     │     └─ Try: counts → place sum (+,−,×,÷,digit-sum) → opposite sum
  │     └─ Each letter = own number ──► TYPE 2
  │           └─ Try: ×2+1, squares, opposite place, ×1 ×2 ×3, digit sum
  │
  ├─ Sentences with codes?  ──► MIXED OLD (compare sentences, find common word/code)
  │
  ├─ Hidden mix like S3Z, #4K?  ──► MIXED NEW (first, last, total, 3rd, 2nd-last, symbol rules)
  │
  └─ 0s and 1s / machine?  ──► BINARY (double chart: 1, 2, 4, 8, 16, 32…)
```

### ✨ Golden Rules

1. **Learn the alphabet places and opposites first.** Everything depends on it.
2. **Write place numbers** for the letters — gaps reveal logic quickly.
3. **Check Forward → Reverse → Cross** in that order.
4. If the logic is **not neat**, it's the wrong pattern — don't force it.
5. **Use the options!** In exams, you usually only need to knock out 3 wrong options.
6. In Number Coding: **counts first**, then **sums**, then **opposites**.
7. In Mixed Coding: **compare sentences**, and **use shared words** as hints.
8. **Wrap around:** past Z, subtract 26; below A, add 26.
9. **Practice daily** — speed comes from seeing the same patterns again and again.
